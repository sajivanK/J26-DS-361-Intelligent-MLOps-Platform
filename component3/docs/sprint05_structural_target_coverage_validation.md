## 5. Validation Result Model

ValidationStatus defines:

- PASS
- FAIL
- REVIEW
- NOT_EVALUATED

ValidationStageResult contains:

- stage
- status
- metrics
- reasons

Results can be serialized using to_dict().

The current structural validator returns PASS or FAIL.
The other statuses support future validation stages.

## 6. Structural Validation Checks

Implemented checks include:

1. Synthetic input is a pandas DataFrame.
2. Prepared metadata uses the expected data structure.
3. Dataset is not empty.
4. No duplicate columns.
5. Synthetic columns match expected feature columns.
6. Continuous/categorical metadata is consistent.
7. Feature-type mapping agrees with declared columns.
8. Missing values are detected.
9. Continuous features have numeric types.
10. Infinite numerical values are detected.
11. Unseen categorical values are identified.
12. Numerical observed-range violations are recorded.
13. Target coverage is evaluated using existing safe logic.
14. Invalid target coverage thresholds are rejected.

## 7. Target Coverage Policy

The smoke experiment used:

min_target_coverage = 0.80

This threshold is provisional and has not been calibrated
through downstream repair experiments.

A generated dataset fails the structural stage if its
target coverage is below the configured threshold.

Passing target coverage does not establish synthetic-data
fidelity, privacy, or downstream utility.

## 8. Numerical Range Diagnostics

The validator records numerical values outside the
minimum and maximum observed in generator training data.

These values are diagnostic observations, not automatic
rejection conditions.

Observed training ranges are not necessarily the true
permitted domains of the underlying features.

Future validation work should distinguish:
- Observed statistical ranges
- Known physical or domain constraints
- Distribution similarity
- Numerical boundary concentration
